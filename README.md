# Proyecto-RUNWAY
Este desarrollo web esta diseñado para ofrecer un espacio digital enfocado en la moda, donde los usuarios pueden compartir sus ideas, estilos, outfits, tendencias y propuestas creativas. RUNWAY busca crear una comunidad donde cualquier persona pueda expresar su visión de la moda, descubrir nuevas ideas y conectar con diferentes estilos de una manera visual, moderna y dinámica.
